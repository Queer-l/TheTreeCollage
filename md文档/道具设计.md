# 道具设计

本文档用于配置当前项目的线索 / 道具 `ClueSO`。  
每个道具在 Unity 中使用 `Tools > Clue SO Generator` 创建，生成后放入 `Assets/SOS/线索SO`，再在 `ClueManager.allClues`、剧情节点 `rewardClue`、分支 `requiredClue` 中引用。

## 字段说明

| 字段 | 说明 |
|---|---|
| clueId | 线索唯一 ID，不要重复。 |
| clueName | 线索 / 道具显示名称。 |
| clueIntro | 线索详情界面显示的介绍文本。 |
| clueImage | 线索图标或详情图，美术需求见“图片需求”。 |
| isKeyClue | 是否为影响主线、结局或关键分支的线索。 |
| storyFlagOnCollect | 获得该线索时建议写入的剧情 flag。当前 `ClueSO` 有字段，后续可在获得线索逻辑中接入。 |

## 详细道具文本

### 1. 宝树果实

- clueName：宝树果实
- clueId：1
- isKeyClue：true
- storyFlagOnCollect：`FLAG_GOT_TREE_FRUIT`
- 获取节点：预留，建议在调查宝树或村民供奉处获得。
- 图片需求：畸形果实，表皮有病态绿光、腐败黄斑和类似血管的纹理；整体看似鲜活但令人不适。
- clueIntro：  
  村民口中能治百病的“宝树果实”。它不像普通植物的果实，表皮温热，纹理像细小血管一样缓慢起伏。父亲和许多村民相信它带来了健康，但小明很难把这种东西和“治愈”联系在一起。

### 2. 大白兔奶糖

- clueName：大白兔奶糖
- clueId：2
- isKeyClue：false
- storyFlagOnCollect：`FLAG_GOT_WHITE_RABBIT_CANDY`
- 获取节点：4001
- 图片需求：白色糖纸包裹的奶糖，包装可有兔子意象，但不要直接复刻真实商标。
- clueIntro：  
  父亲从柜子里翻出来的奶糖，糖纸有些旧，却被保存得很干净。它不是什么重要证据，只是父亲还把小明当成孩子的证明。越是普通，越让之后发生的事显得沉重。

### 3. 水井里的锈剑

- clueName：水井里的锈剑
- clueId：3
- isKeyClue：true
- storyFlagOnCollect：`FLAG_GOT_RUSTY_SWORD`
- 获取节点：5402
- 图片需求：八面剑，半截带锈，剑身残留泥水和青铜冷光；图标中应突出“古旧”和“仍然锋利”的矛盾感。
- clueIntro：  
  从水井底捞出的锈蚀八面剑。它的制式古老，像是本不该出现在这口井里的东西。剑身已经斑驳，却仍有一线冰冷的锋芒，仿佛长久等待着再次被使用。

### 4. 一把铜钥匙

- clueName：一把铜钥匙
- clueId：4
- isKeyClue：true
- storyFlagOnCollect：`FLAG_GOT_COPPER_KEY`
- 获取节点：5005
- 图片需求：氧化发绿的旧铜钥匙，造型可带一点道观或古旧纹饰。
- clueIntro：  
  一把沉甸甸的铜钥匙，钥匙齿磨损严重，表面覆盖着铜绿。它不像普通家门钥匙，更像是某个老旧建筑的遗物。也许它能打开村里那座残破道观的门。

### 5. 一把铁钥匙

- clueName：一把铁钥匙
- clueId：5
- isKeyClue：true
- storyFlagOnCollect：`FLAG_GOT_IRON_KEY`
- 获取节点：5006
- 图片需求：黑铁色老式钥匙，锈迹明显，造型更朴素实用。
- clueIntro：  
  一把普通的铁钥匙，边缘有明显锈迹。它不像铜钥匙那样古怪，却带着很强的现实感。小明猜测它也许能打开卫生所某扇不常使用的门。

### 6. 不知名丹药

- clueName：不知名丹药
- clueId：6
- isKeyClue：false
- storyFlagOnCollect：`FLAG_GOT_UNKNOWN_PILL`
- 获取节点：5302
- 图片需求：暗金色或赤褐色药丸，放在破旧木盒、瓷瓶或黄符旁，带轻微诡异光泽。
- clueIntro：  
  老道观里发现的丹药，不知在这里放了多少年。它被保存得异常完整，甚至散发着一点不自然的光泽。“一颗金丹吞入腹，我命由我不由天”这种话听起来豪迈，但小明知道，来历不明的东西最好别吃。

### 7. 医生的笔记

- clueName：医生的笔记
- clueId：7
- isKeyClue：true
- storyFlagOnCollect：`FLAG_GOT_DOCTOR_NOTE`
- 获取节点：预留 / 卫生所后门
- 图片需求：旧笔记本，页面杂乱，有涂黑段落、医学草图、树根或果实样本记录；最后一页可露出“它们很不喜欢酒”。
- clueIntro：  
  一本字迹凌乱的研究笔记，内容大多围绕“宝树”、村民身体变化和不明污染展开。大量文字被用黑笔涂掉，最后一页只剩下一行仓促写下的话：它们很不喜欢酒。

### 8. 一瓶酒

- clueName：一瓶酒
- clueId：8
- isKeyClue：true
- storyFlagOnCollect：`FLAG_GOT_WINE`
- 获取节点：5004
- 图片需求：普通村镇白酒瓶，透明玻璃或简陋标签，瓶身可有旧灰尘。
- clueIntro：  
  一瓶普通的酒，看起来和村里饭桌上常见的东西没有区别。医生笔记里提到“它们很不喜欢酒”，这让它突然变得不那么普通。也许乙醇能干扰宝树制造的幻觉。

### 9. 一瓶药

- clueName：一瓶药
- clueId：9
- isKeyClue：false
- storyFlagOnCollect：`FLAG_GOT_DOCTOR_MEDICINE`
- 获取节点：5204
- 图片需求：无标签药瓶，白色药片或浑浊液体，瓶口有临时封口。
- clueIntro：  
  年轻医生递给小明的一瓶药，没有标签，也没有说明。医生没有解释它的用途，只是让小明拿着。它也许能救命，也许只是另一个不该轻易相信的东西。

### 10. 揉皱的小广告

- clueName：揉皱的小广告
- clueId：10
- isKeyClue：false
- storyFlagOnCollect：`FLAG_GOT_CRUMPLED_AD`
- 获取节点：5003
- 图片需求：廉价红黄彩印广告，纸面揉皱，字体夸张，带乡镇墙贴和“包治百病”的感觉。
- clueIntro：  
  一张被揉皱的小广告，上面写着“灵丹妙药，包治百病，清朝中医家族家传秘方，治不好，我包赔！”它廉价、夸张、荒唐，却和村民对宝树的狂热信任有着某种相似之处。

### 11. 一封信

- clueName：一封信
- clueId：11
- isKeyClue：true
- storyFlagOnCollect：`FLAG_GOT_LETTER`
- 获取节点：5002
- 图片需求：泛黄旧信纸，折痕明显，手写字迹凌乱，可露出“矿上”“春柏”“出事”等关键词。
- clueIntro：  
  父亲写给陈春柏的一封信，语气焦急，像是在劝对方不要继续追查矿上的事。信里没有把话说透，却足够让人明白，很多人早就知道问题存在。它是最终对峙时最沉重的证据。

### 12. 红糖糕

- clueName：红糖糕
- clueId：12
- isKeyClue：true
- storyFlagOnCollect：`FLAG_GOT_BROWN_SUGAR_CAKE`
- 获取节点：5501
- 图片需求：手作红糖糕，放在旧盘子或油纸上，颜色温暖但构图带一点哀伤。
- clueIntro：  
  陈奶奶亲手做的红糖糕。她说陈春柏从前最爱吃这个。它看起来只是普通点心，却承载着一个母亲漫长的等待和无法愈合的伤口。某些记忆，也许连古老的东西都无法彻底吞掉。

## 配置注意

- `clueId = 1` 当前已有测试数据占用时，需要确认是否把 `TEST.asset` 改为“宝树果实”，或删除测试资产后重新生成正式道具。
- 关键主线推荐优先制作 SO：`一封信`、`一瓶酒`、`水井里的锈剑`、`红糖糕`、`医生的笔记`。
- 剧情节点中“道具需求”对应 `StoryChoice.requiredClue` 或后续节点进入条件。
- 剧情节点中“道具奖励”对应 `StoryNodeSO.rewardClue`。
- 如果后续要让 `storyFlagOnCollect` 生效，需要在获得线索时调用 `PlayerData.AddStoryFlag(clue.storyFlagOnCollect)`。
